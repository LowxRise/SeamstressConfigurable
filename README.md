A few settings for Seamstress, available in Risk of Options.

- It Hungers lifesteal: 1–25%, default 15%. Missing-health and proc scaling stay the same.
- No self bleed or needle gain: checked by default. Only applies while Retaliate's Insatiable is active. Its activation, duration and healing-to-barrier behavior are unchanged. Other utilities are untouched.
- Skewer health cost: 0–25% of full combined health, default 15%.

Changes apply to the next relevant hit, shot or bleed tick, without restarting. Requires Seamstress and Risk of Options. Built against Seamstress 1.6.10; other versions have not been checked.

For multiplayer, install it on every player's profile and use matching settings. Original skill descriptions may still show the original values.

Import the ZIP through r2modman's Settings > Profile > Import local mod.
